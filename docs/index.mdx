# TSIA2 Practice: A Two-Pass Review Loop

Review is most useful when it answers two different questions:

1. Why was this answer wrong?
2. What should change during the next practice set?

Trying to answer both at once often produces vague notes such as “read more carefully.” A two-pass loop keeps correction and strategy separate.

## Pass one: reconstruct the decision

Return to each missed or uncertain question without looking at the answer explanation first.

Write three short lines:

- **Task:** What did the question ask you to find?
- **Evidence or setup:** Which sentence, value, relationship, or rule should control the answer?
- **Decision point:** Where did your reasoning move toward the wrong choice?

For a reading item, the decision point might be treating a related detail as the main claim. For a quantitative item, it might be applying a percent to the wrong base. For a writing item, it might be choosing a grammatically correct transition that does not match the paragraph’s logic.

Only after reconstructing the decision should you compare your work with the correct answer.

## Pass two: assign a repair action

Give the error one process label:

- **task mismatch** — solved a different problem than the one asked;
- **evidence gap** — chose before locating support;
- **translation error** — converted words into the wrong relationship;
- **rule confusion** — mixed two grammar or math rules;
- **calculation slip** — sound setup, inaccurate execution;
- **premature commitment** — stopped comparing choices too early.

Then choose one repair action small enough to use in the next session. Examples:

- underline the requested quantity before calculating;
- predict the passage claim before opening the choices;
- write units beside every number;
- name the relationship between two sentences before selecting a transition;
- recheck the base value in every percent problem.

The action should describe an observable step, not a personality trait.

## Use a four-column review table

| Question | Decision point | Error label | Next action |
|---|---|---|---|
| Reading inference | Extended the claim beyond the cited paragraph | evidence gap | Quote the controlling phrase first |
| Percent change | Used the final value as the base | translation error | Mark original and new values |
| Sentence transition | Chose contrast instead of result | task mismatch | State the paragraph relationship |

Keep the table short. Three carefully diagnosed questions usually teach more than copying explanations for an entire set.

## Re-test the action

On the next practice set, track whether you performed the chosen action. Improvement is not only a higher score. It is also fewer repeated decision errors.

If the same label appears again, make the action more specific. “Check evidence” can become “write the line number before selecting an inference.” If the action works, keep it for another session before adding a new one.
